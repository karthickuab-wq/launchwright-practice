# Where the link rules come from

What the idea-intake skill relies on about other sites' terms, each with its source and the date it was read. When a rule changes, update this file and the skill's "Which pages Claude may open" together.

| Site | The rule | What the skill does | Source and date |
| --- | --- | --- | --- |
| **Spotify** (open.spotify.com, spotify.link) | Spotify's User Guidelines forbid crawling or scraping the service, or using any automated means (bots, scrapers, spiders) to view, access or collect information from it, and forbid using the service or its content to train machine-learning or AI models | Never opens a Spotify page. Finds the show's own website or RSS feed instead, or asks the user to paste the show notes or transcript | [Spotify User Guidelines](https://www.spotify.com/us/legal/user-guidelines/). Not read directly: spotify.com can't be opened from the environment this skill was written in. The rule is as quoted in web search results on Nov 18, 2026, and as the owner read it the same day |
| **Spotify for Creators** (creators.spotify.com, and feeds on anchor.fm) | Its own terms weren't read. It's Spotify's podcast host, formerly Anchor | Treated like Spotify: its pages and feeds aren't opened | — |
| **YouTube** (youtube.com, m.youtube.com, music.youtube.com, youtu.be) | YouTube's Terms of Service bar accessing the service by automated means (robots, botnets or scrapers), except public search engines that follow YouTube's robots.txt file, or with YouTube's prior written permission | Never opens a YouTube page. Asks the user to paste the video's description or transcript | [YouTube Terms of Service](https://www.youtube.com/t/terms), dated Dec 15, 2023. Not read directly: youtube.com can't be opened from here. The rule is as quoted in web search results on Nov 18, 2026, and as the owner read it the same day |
| **Apple Podcasts** (podcasts.apple.com) | Apple's Media Services Terms bar "any software or automated process to scrape, copy, or monitor the Content or Services", and Apple's Website Terms of Use bar any "deep-link", "page-scrape", "robot", "spider" or other automatic device to access, copy or monitor the site | Treated like Spotify: never opened. An Apple Podcasts address usually spells the show's name, which may be read from the address without opening it | [Apple Media Services Terms](https://www.apple.com/legal/internet-services/itunes/), [Apple Website Terms of Use](https://www.apple.com/legal/internet-services/terms/site.html). Not read directly: www.apple.com can't be opened from here. The quotes are from web search results on Nov 18, 2026 |
| **Other listening apps and podcast directories** (Overcast, Pocket Casts, Castbox, Amazon Music and the like) | Their terms weren't read | Not opened. The show's own website or feed is the original source anyway | — |
| **The show's own website and RSS feed**, including when a podcast host runs them (Buzzsprout, Libsyn, Podbean, Transistor, Simplecast, Captivate, Substack and the like) | A feed is published so that any podcast app can read it, and a show's website is its public home | Read: the episode's page or its item in the feed, and a transcript file the feed links to on the same host | — |

Read the Spotify, YouTube and Apple pages themselves again when they can be opened, and update the dates here.
