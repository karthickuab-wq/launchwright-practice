# The question sweep

Everything the build needs from the user, asked once before it starts, with the answers in the user's words.

## Decisions
Each question, the options offered, the answer and the date.

## Accounts
Each service the app needs an account for, and whether the user has made it.

## Keys
Each key this project needs, by name only, and whether the user has added it to the app's own keys environment. Never the key itself.

## Review window
When the user can usually review. Also saved in the kit's settings.

## Skipped
Questions the user skipped, and the work that waits on each.
