# Lessons

What this project learned, from each checkpoint's retrospective and from anything that went wrong.

## Lessons
Each lesson: what happened, the whole kind of problem it belongs to, and the rule that stops it happening again. Lessons that apply to every project are passed on to the plugin.

### Apple's App Store pages read during an idea review (Nov 23, 2026)
- **What happened:** While checking a research brief's ideas (not a formal market check), a thread opened an apps.apple.com page in the built-in browser and quoted its rating. The market check's sources list bars Apple's App Store pages.
- **The kind of problem:** The "never read" list sits inside the market-check skill, so work that isn't formally a market check (brief reviews, idea hunts, quick competitor looks) can miss it.
- **The rule:** Any competitor lookup, in any skill or ad-hoc review, follows the market check's sources list: no Apple App Store pages, no sites that copy them, no Spotify or YouTube. Use the app's own website, or ask the user for a screenshot. Kit suggestion: move the "never read" list into the front door or AGENTS.md so every thread sees it.
